GitHub Pages 部署指南

1 建立 GitHub Repository

  1. 登入 GitHub 並點擊右上角 + -> New repository。
  2. Repo 名稱設定為 cat-links (或自訂)。
  3. 設定為 Public，並點擊 Create repository。

2 上傳檔案與開啟 GitHub Pages

  1. 將本頁面存為 index.html，並上傳範例 links.json。
  2. 進入 Repo 的 Settings -> Pages。
  3. Source 選擇 Deploy from a branch，Branch 選擇 main / root 並 Save。
  4. 等待數分鐘即可獲取網址：https://.github.io//。

3 申請 Personal Access Token (PAT)

  1. 點擊 GitHub 頭像 -> Settings -> Developer Settings。
  2. 點擊 Personal access tokens -> Tokens (classic)。
  3. 點擊 Generate new token (classic)。
  4. 勾選 repo 權限（允許寫入檔案）。
  5. 生成後複製 Token 碼（注意：僅會顯示一次！）。

4 一鍵自動 Commit Save

登入本頁管理員（密碼：0115），於上方「GitHub API 設定」輸入 Username、Repo 名稱與 PAT，點擊「一鍵 Save 至 GitHub」即可直接更新！
